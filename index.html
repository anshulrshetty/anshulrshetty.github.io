About me

I build the tools that turn data into lap time. My focus is vehicle dynamics and simulation: constructing lap time models, correlating them against real telemetry, and translating driver behaviour into concrete setup actions.

That thread runs through everything on this page - a dissertation simulating 2026-regulation Formula 1 cars in AVL VSM, PITWALL, a desktop application that fingerprints driving style from ACC telemetry and develops driver-specific setup analysis, and a patent-pending tyre pressure control system that closed the loop on real hardware.

PITWALL - Driver-Specific Setup Optimisation

A telemetry-driven race engineering platform for Assetto Corsa Competizione. It learns how a driver actually drives - trail-brake fraction, time to full throttle, steering activity, exit commitment, measured per corner speed band - then structures one-factor-at-a-time setup experiments and driver-specific performance analysis.

Nine views take a session from ingestion through to recommendations, including six setup-input areas so every lap is traceable back to its configuration. Ingestion is built for real telemetry rather than clean samples: native MoTeC binary telemetry and i2 CSV exports through one pipeline, automatic unit detection, multi-rate channel resampling, and a truncation guard. Commissioned on real ACC stints using the Aston Martin V8 Vantage GT3 at Silverstone GP and processed through both export formats to confirm the driver fingerprint agrees across them.

Current development includes sensitivity regression and a human-in-the-loop recommendation architecture so setup recommendations remain explainable and subject to engineer and driver judgement.

217 corner observations, single-driver validation 55 telemetry channels parsed <0.01 cross-format feature delta
